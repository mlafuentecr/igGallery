# IG Gallery

Extensión de Chrome que transforma las listas **Following** y **Followers** (también reconoce **Siguiendo** y **Seguidores**) en una galería visual. Permite elegir entre **2 columnas con fotos grandes** o **3 columnas con fotos semi grandes**, ajustar manualmente el tamaño de las fotos y activar un auto-scroll gradual para cargar más perfiles.

IG Gallery se limita a mejorar la visualización local de estas listas dentro de `instagram.com`.

## Instalar

1. Abre `chrome://extensions` en Chrome.
2. Activa **Modo de desarrollador**.
3. Selecciona **Cargar descomprimida**.
4. Elige esta carpeta: `outputs/instagram-following-grande`.
5. Recarga Instagram y abre la lista **Following**.

Si ya la habías instalado, en `chrome://extensions` pulsa el botón de recarga de la extensión y luego recarga Instagram. Chrome solo incorpora cambios de una extensión después de esa recarga.

## Privacidad

IG Gallery no recopila, vende ni transmite datos personales, perfiles, credenciales ni contenido de Instagram. Los ajustes de visualización se guardan mediante Chrome Sync para que se conserven entre navegadores vinculados del usuario. Consulta la [política de privacidad](PRIVACY.md).
